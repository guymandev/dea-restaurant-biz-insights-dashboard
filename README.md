# Restaurant Business Insights Dashboard

## Overview

This repository contains the Streamlit presentation layer for the Restaurant Business Insights capstone project.

The dashboard connects directly to Amazon Athena and visualizes curated restaurant analytics marts produced by the upstream AWS data pipeline.

[Restaurant Business Insights Dashboard](https://dea-restaurant-biz-insights-dashboard-pf2eonu4wgytgnejaxfupy.streamlit.app/)

## Architecture

The Streamlit app is the final presentation layer in the end-to-end restaurant analytics platform.

```text
SQL Server → AWS Glue → S3 Raw/Silver/Gold/Marts → Glue Data Catalog → Athena → Streamlit
```

This dashboard does not process raw source data directly. Instead, it queries the finalized mart tables registered in the AWS Glue Data Catalog and made available through Athena.

## Data Source

The dashboard queries the following Athena / Glue Data Catalog database:

```text
restaurant_analytics
```

Primary mart tables used by the dashboard:

```text
customer_clv_snapshot
customer_daily_clv
customer_rfm
daily_sales
item_sales
option_sales
restaurant_daily_sales
restaurant_item_sales
```

These tables are generated by the upstream AWS Glue pipeline and stored as partitioned Parquet datasets in Amazon S3.

## Security and Access

The deployed Streamlit app uses a dedicated IAM user stored in Streamlit secrets.

That IAM user has scoped permissions to:

* Run Athena queries
* Read Glue Data Catalog metadata
* Read S3 mart data
* Write and read Athena query result files
* Use the project KMS key to decrypt encrypted S3 resources

The app does not store AWS credentials in the repository.

## Streamlit Secrets

For deployment, the app expects the following secrets in Streamlit Cloud:

```toml
[aws]
aws_access_key_id = "YOUR_ACCESS_KEY_ID"
aws_secret_access_key = "YOUR_SECRET_ACCESS_KEY"
region_name = "us-east-2"
athena_database = "restaurant_analytics"
athena_output_location = "s3://dea-restaurant-biz-insights/athena-query-results/"
```

For local development, a `.streamlit/secrets.toml` file can be used with the same structure. This file should not be committed to GitHub.

## Local Development Setup

### 1. Clone the repository

```bash
git clone https://github.com/guymandev/dea-restaurant-biz-insights-dashboard.git
cd dea-restaurant-biz-insights-dashboard
```

### 2. Create and activate a virtual environment

```bash
python3 -m venv py3_12
source py3_12/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure AWS credentials

Option A: Use a local AWS CLI profile.

```bash
aws configure --profile restaurant-dashboard
```

Then run the app with:

```bash
AWS_PROFILE=restaurant-dashboard streamlit run home.py
```

Option B: Use a local Streamlit secrets file.

Create:

```text
.streamlit/secrets.toml
```

Example:

```toml
[aws]
profile_name = "restaurant-dashboard"
region_name = "us-east-2"
athena_database = "restaurant_analytics"
athena_output_location = "s3://dea-restaurant-biz-insights/athena-query-results/"
```

Then run:

```bash
streamlit run home.py
```
